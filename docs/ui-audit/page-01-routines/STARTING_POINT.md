# Point de départ — PAGE-01 Routines

Date : 2026-09-15

## Page réelle

`http://localhost:8081/routines`

## Visuel actuellement observé

- header blanc compact avec icône `R` à gauche et thème à droite ;
- météo bleue sur toute la largeur avec tenue et action `Adapter` ;
- routine principale blanche à gauche ;
- calendrier lavande à droite à largeur desktop ;
- section `Autres routines` ;
- actions `Enchaîner`, `Gérer` et `Créer` ;
- navigation flottante basse Routines / Activités / Parent ;
- grands ronds pastel partiellement visibles dans le fond.

Ce visuel est le produit réel de départ. Il contient des travaux précédents mais doit être jugé comme un existant, sans présumer qu’une composition de page est validée.

La reprise à zéro concerne la composition de PAGE-01, pas l’identité globale. La palette pastel sémantique, les modes clair/sombre, la typographie ronde, les rayons protecteurs, les ronds de fond, la marque `R` + trois points et la différence entre outils parentaux calmes et moments accompagnés vivants restent obligatoires.
