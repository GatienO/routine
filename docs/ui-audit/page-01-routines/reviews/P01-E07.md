# P01-E07 — Accès Parent protégé

Date : 2026-09-16
Statut : **validé — P1 Petit cadenas sur l’engrenage**

## Ce qui existe réellement

Lorsque le PIN parental est activé, l’onglet Parent affiche déjà un petit cadenas. Un appui depuis une page non parent désactive d’abord le mode parent puis remplace la route courante par `/pin?redirect=/parent`. La navigation basse disparaît sur l’écran PIN. Après saisie correcte, l’app active le mode parent et revient exactement vers la destination parent demandée. Quitter l’espace Parent par Routines ou Activités le reverrouille.

Le PIN actuel comporte quatre chiffres et reste entièrement local dans le store persistant. Le même écran gère la création initiale, la confirmation, l’erreur de confirmation, le code erroné et un délai après trop d’essais. Il ne constitue pas un chiffrement ni une protection forte de l’appareil : c’est une barrière parentale simple contre un accès accidentel.

L’écran visuel actuel doit être repris lors de l’intégration : il utilise encore l’ancien style, des couleurs codées en dur et plusieurs textes sans accents (`Creez`, `Acces`, `securises`). Ces défauts sont conservés dans l’inventaire de construction, pas dans les propositions ci-dessous.

## Invariants communs

- la destination reste nommée **Parent** dans les trois variantes ;
- le verrou n’apparaît que si un PIN a réellement été configuré ;
- un appui protégé ouvre un écran PIN dédié et masque la navigation basse ;
- retour explicite vers l’écran précédent sans modifier le mode parent ;
- quatre chiffres, quatre indicateurs non révélateurs, pavé numérique et suppression accessibles ;
- création et confirmation du PIN si aucun code n’existe encore ;
- message d’erreur compréhensible, sans afficher ni journaliser le code ;
- redirection limitée à `/parent` et ses sous-routes ;
- sortie de l’espace Parent = verrouillage immédiat ;
- style clair et sombre cohérent avec A1, R1, H3, T1 et N2.
- icônes de navigation et de sécurité strictement linéaires, simples et issues de la même famille Phosphor Regular ; aucun cadenas plein.

## P1 — Petit cadenas sur l’engrenage — recommandé

L’onglet conserve l’engrenage linéaire, repère stable de la destination Parent, et reçoit un petit cadenas filaire superposé uniquement lorsqu’il est protégé. Après déverrouillage, le cadenas disparaît sans changer l’icône principale.

- Mobile : indicateur compact dans la cible Parent; aucun libellé supplémentaire.
- Tablette/bureau : même traitement, sans agrandir la barre.
- Accessibilité : libellé dynamique « Parent, verrouillé » ou « Parent, déverrouillé »; le badge n’est pas lu séparément.
- Avantage : sécurité annoncée sans perdre l’identité de la destination.
- Risque : le petit badge doit garder un contraste suffisant sans sembler être une notification.

## P2 — Cadenas à la place de l’engrenage

Lorsque l’espace est verrouillé, le cadenas remplace complètement l’engrenage. Une fois le PIN accepté, l’engrenage réapparaît.

- Mobile : état très visible, même sur un petit écran.
- Tablette/bureau : lecture immédiate à distance.
- Accessibilité : même libellé dynamique que P1.
- Avantage : verrouillage impossible à manquer.
- Risque : l’icône de destination change selon l’état et peut faire croire à une quatrième fonction plutôt qu’à l’espace Parent.

## P3 — Protection révélée au toucher

L’onglet conserve toujours l’engrenage, sans cadenas visible. L’écran PIN apparaît seulement après l’appui.

- Mobile, tablette et bureau : barre la plus épurée.
- Accessibilité : le nom accessible doit tout de même annoncer « Parent, verrouillé » avant l’appui.
- Avantage : aucune surcharge graphique.
- Risque : la demande de code surprend; l’état protégé n’est pas visible et le parent peut croire que l’appui n’a pas mené à la destination attendue.

## Écran PIN commun aux trois propositions

Le visuel interactif montre le même écran après appui sur Parent : fond continu clair/sombre, marque flottante, cadenas filaire, titre **Espace parent**, instruction courte, quatre points, pavé 1–9/0 et retour. La barre N2 disparaît pendant cette étape pour éviter toute sortie ambiguë. Les variantes de création, confirmation et erreur reprennent exactement cette structure et seront spécifiées dans la todo d’intégration.

## Recommandation

**P1 — Petit cadenas sur l’engrenage.** C’est le meilleur équilibre entre prévisibilité, discrétion et stabilité : Parent reste toujours reconnaissable, tandis que la protection est annoncée avant l’appui.

## Porte de décision

Décision utilisateur du 2026-09-16 : **P1 — Petit cadenas sur l’engrenage**.

L’engrenage linéaire reste l’icône principale de Parent. Un petit cadenas filaire lui est superposé seulement lorsque le PIN est actif et que l’espace est verrouillé. Le libellé accessible annonce explicitement l’état. L’écran PIN dédié et toutes ses protections restent inchangés.
