# Archive — premier audit de Routines

Ce document remplace l’audit exploratoire antérieur, fondé sur une page personnelle par enfant, un explorateur dense et un compositeur de session. Ces pistes ont été explicitement abandonnées.

Décision retenue : Routines est un outil parental global, avec une prochaine routine claire, des participants choisis au lancement, deux outils contextuels Calendrier et Météo, puis un mode accompagné plein écran.

Les constats encore utiles sont intégrés dans [la file de refonte](../MASTER.md). Cette archive ne contient plus de tâches actives.
